Steps for Installing Docker on Ubuntu
Step 1: Update Software Repositories using the following command on the terminal.

sudo apt update

After that 
Step 2: Install Docker using the following command

sudo apt install docker.io -y

So Aftrer that we have Step 3: Enable and start the docker service by using the following commands.

sudo systemctl enable docker --now

Step 4: Check Docker Version.

docker --version


Executing the Docker Command Without Sudo
We will get a permission denied error as a regular user doesn't have permission to execute docker commands. Know we need to add the the user to the required group.

Step 1: So we need to add an Ubuntu user to the docker group. 

#sudo usermod -aG docker $USER
    or
#sudo usermod -aG docker ubuntu

The following command helps in knowing whether current add user assigned to docker group or not:
getent group docker


Refresh the group permission to use updated one with running following command:
newgrp docker

Step 2: Restart the docker daemon which is already running. After restarting only the changes will comes into effect.

sudo service docker restart

Step 3: Leave the current SSH terminal and re-login with SSH. then carry out.

docker ps

$ docker run <image_name>
To give name of container
$ docker run --name <container_name> <image_name>

List Docker images: "docker images" this command will list all the docker images which are available in the docker.
To Pull Docker Images: "docker pull <Name of the image>" it will pull the required images which are stored in the docker hub registry or repository.

deploying your Spring Boot WAR inside a Tomcat container is the most reliable way to run JSP pages. Here’s a clean Dockerfile you can use:



And Dockerfile data is :



# Use official Tomcat image with JDK
FROM tomcat:9.0-jdk17



# Remove default ROOT webapp to avoid conflicts
RUN rm -rf /usr/local/tomcat/webapps/ROOT



# Copy your WAR file into Tomcat's webapps directory


COPY target/springboot-jsp-app.war /usr/local/tomcat/webapps/ROOT.war



# Expose Tomcat default port
EXPOSE 8080



# Start Tomcat
CMD ["catalina.sh", "run"]





After this build the WAR file

mvn clean package


And Run It

Build the Docker image:

docker build -t springboot-jsp-tomcat .
After that Run the container:

docker run -p 8080:8080 springboot-jsp-tomcat

+++++++++++++++++ how to connect our MongoDb database with our Spring Appplications +++++++

To connect your Spring Boot application with a MongoDB instance running inside a Docker \
Run MongoDB in Docker
Start MongoDB using the official image:

docker run -d \
  --name my-mongo \
  -p 27017:27017 \
  -e MONGO_INITDB_ROOT_USERNAME=root \
  -e MONGO_INITDB_ROOT_PASSWORD=example \
  mongo:latest


-p 27017:27017 → exposes MongoDB on your local machine’s port 27017.

MONGO_INITDB_ROOT_USERNAME and MONGO_INITDB_ROOT_PASSWORD → credentials for authentication.

Configure application.properties (or application.yml)
Tell Spring Boot how to connect to MongoDB:

spring.data.mongodb.uri=mongodb://root:example@localhost:27017/mydatabase



And if you are using or created own network okay then below is the commands used fo this 

Create the Network
You already did this, but for completeness:
docker network create mynetwork


Run MongoDB on That Network
Attach MongoDB to mynetwork:

docker run -d \
  --name my-mongo \
  --network mynetwork \
  -e MONGO_INITDB_ROOT_USERNAME=root \
  -e MONGO_INITDB_ROOT_PASSWORD=example \
  mongo:latest

Notice: no -p 27017:27017 is required if you only want containers inside the network to talk to MongoDB. If you also want to connect from your host machine (e.g., MongoDB Compass), keep the -p.

Run Your Spring Boot App on the Same Network
If you package your Spring Boot app as a Docker image:

docker build -t my-spring-app .

docker run -d \
  --name spring-app \
  --network mynetwork \
  -e SPRING_DATA_MONGODB_URI=mongodb://root:example@my-mongo:27017/mydatabase \
  my-spring-app

Key Point: Use the Container Name as Host
Inside mynetwork, containers can resolve each other by name.
So in your Spring Boot config (application.properties or environment variable):

in that .properties file you can mentioned like 
spring.data.mongodb.uri=mongodb://root:example@my-mongo:27017/mydatabase

my-mongo is the container name of MongoDB.

No need to use localhost because from Spring Boot’s perspective, MongoDB is another container on the same network.

Verify Connectivity
You can test by entering the Spring Boot container and pinging MongoDB:

docker exec -it spring-app ping my-mongo

Or connect with the Mongo shell:

docker exec -it my-mongo mongosh -u root -p example



++++++++++++++++++++++++  Can you give one Example like how to communicate three container using docker Suppose one container is for our App  And Second one is for our mysql And third is one is for our MongoDB Database ?
  +++++++++++++++++++


Got it — no Docker Compose for now. Let’s do this step by step with plain docker run commands and a shared network. You’ll have three containers:

Spring Boot app
MySQL
MongoDB

Create a Network
docker network create mynetwork


Second step is that like Run MySQL on That Network

docker run -d \
  --name mysql-db \
  --network mynetwork \
  -e MYSQL_ROOT_PASSWORD=rootpass \
  -e MYSQL_DATABASE=mymysqldb \
  -e MYSQL_USER=appuser \
  -e MYSQL_PASSWORD=apppass \
  -p 3306:3306 \
  mysql:8.0

Aftrer that we have to Run MongoDB on That Network 

docker run -d \
  --name mongo-db \
  --network mynetwork \
  -e MONGO_INITDB_ROOT_USERNAME=root \
  -e MONGO_INITDB_ROOT_PASSWORD=example \
  -p 27017:27017 \
  mongo:latest

After that we have to Run Your Spring Boot App on That Network
First, build your app image using docker file :

docker build -t spring-app .

After build is done now we have to run the container okay 

Then run it:
docker run -d \
  --name spring-app \
  --network mynetwork \
  -e SPRING_DATASOURCE_URL=jdbc:mysql://mysql-db:3306/mymysqldb \
  -e SPRING_DATASOURCE_USERNAME=appuser \
  -e SPRING_DATASOURCE_PASSWORD=apppass \
  -e SPRING_DATA_MONGODB_URI=mongodb://root:example@mongo-db:27017/mydatabase \
  -p 8080:8080 \
  spring-app

And for .properties file we have to do some of the configurations okay 
Key Configurations in Spring Boot
MySQL (JPA/Hibernate):
spring.datasource.url=jdbc:mysql://mysql-db:3306/mymysqldb
spring.datasource.username=appuser
spring.datasource.password=apppass
spring.jpa.hibernate.ddl-auto=update

And for mongoDb we have to add some of the configuratiosn file 

MongoDB (Spring Data MongoDB):
spring.data.mongodb.uri=mongodb://root:example@mongo-db:27017/mydatabase

Notice:

Use container names (mysql-db, mongo-db) instead of localhost.

All three containers are on mynetwork, so they can resolve each other by name.

So for verifications we have to 

Verify
From inside the Spring Boot container:
docker exec -it spring-app ping mysql-db
docker exec -it spring-app ping mongo-db



Both should respond, confirming connectivity.


Now your Spring Boot app can talk to both MySQL and MongoDB without Docker Compose, just using docker run and a shared network.
