Steps to deploy Docker containers on EC2


For your React + Spring Boot + MySQL Pet Store Application, a typical production deployment flow using Docker on AWS EC2 looks like this:

Step 1: Create EC2 Instance

Launch an EC2 instance:

Amazon Linux 2023
t3.medium (recommended)
20-30 GB EBS

Open Security Group Ports:

22   -> SSH
80   -> HTTP
443  -> HTTPS
8080 -> Spring Boot (optional, internal only)

Connect:

ssh -i petstore-key.pem ec2-user@<public-ip>



Step 2: Install Docker

Update server:


sudo yum update -y

Install Docker:
sudo yum install docker -y

Start Docker:

sudo systemctl start docker
sudo systemctl enable docker

Verify:
docker --version


Add user to docker group:

sudo usermod -aG docker ec2-user
newgrp docker



Step 3: Create Backend Docker Image
Spring Boot Dockerfile

FROM eclipse-temurin:21-jdk

WORKDIR /app

COPY target/petstore.jar app.jar

EXPOSE 8080

ENTRYPOINT ["java","-jar","app.jar"]



Build Image:

docker build -t petstore-backend:v1 .

Verify:

docker images


-------------------------------------------------------------------------------------------------------------------

Step 4: Create Frontend Docker Image

React Dockerfile

FROM node:20 AS build

WORKDIR /app

COPY . .

RUN npm install
RUN npm run build

FROM nginx:latest

COPY --from=build /app/build /usr/share/nginx/html

EXPOSE 80



Build:
docker build -t petstore-frontend:v1 .



Step 5: Create AWS ECR Repositories

Create repositories:

petstore-backend
petstore-frontend

Create:

version: '3'

services:

You've completed the coding and created the 4 EC2 instances, which is great progress. The next step is to set up the infrastructure and CI/CD pipeline.

Step 1: Configure MySQL EC2

Connect to the MySQL server:
ssh -i key.pem ec2-user@<MYSQL-IP>


Install Docker:

sudo yum update -y
sudo yum install docker -y
sudo systemctl start docker
sudo systemctl enable docker

Run MySQL Container:
docker run -d \
--name mysql \
-p 3306:3306 \
-e MYSQL_ROOT_PASSWORD=root123 \
-e MYSQL_DATABASE=petstore \
mysql:8

Open Security Group:
Port 3306
Source: Backend EC2 Security Group



Step 2: Configure Backend EC2

SSH to Backend Server:
ssh -i key.pem ec2-user@<BACKEND-IP>

Install Docker:
sudo yum update -y
sudo yum install docker -y
sudo systemctl start docker
sudo systemctl enable docker

Open Security Group:
22  SSH
8080 Spring Boot

Update Spring Boot application properties:

spring.datasource.url=jdbc:mysql://<MYSQL-IP>:3306/petstore
spring.datasource.username=root
spring.datasource.password=root123




Step 3: Configure Frontend EC2

SSH:

ssh -i key.pem ec2-user@<FRONTEND-IP>
Install Docker:
sudo yum install docker -y
sudo systemctl start docker
sudo systemctl enable docker


Open Ports:
22
80
443



Step 5: Install Jenkins

Login Jenkins EC2.

Install Java:
sudo yum install java-17-amazon-corretto -y

Install Jenkins:
sudo wget -O /etc/yum.repos.d/jenkins.repo \
https://pkg.jenkins.io/redhat-stable/jenkins.repo

sudo rpm --import https://pkg.jenkins.io/redhat-stable/jenkins.io-2023.key

sudo yum install jenkins -y

sudo systemctl enable jenkins
sudo systemctl start jenkins

Access:
http://JENKINS-IP:8080
Open Security Group:
8080


Step 6: Install Required Tools on Jenkins

Install:
Docker
Git
AWS CLI
Java 17
NodeJS


Verify:
docker --version
aws --version
git --version
node -v

Step 7: Configure Jenkins Credentials

Add:

GitHub Token
Manage Jenkins
 → Credentials
 
 Add:
 
 github-token
 
 
Step 8: Create Dockerfile
Frontend Dockerfile

FROM node:20 AS build

WORKDIR /app

COPY package*.json ./

RUN npm install

COPY . .

RUN npm run build

FROM nginx:latest

COPY --from=build /app/dist /usr/share/nginx/html

EXPOSE 80



Backend Dockerfile
FROM eclipse-temurin:17

COPY target/*.jar app.jar

EXPOSE 8080

ENTRYPOINT ["java","-jar","/app.jar"]



Step 9: Configure Jenkins Agent Permissions

Allow Jenkins to use Docker:

sudo usermod -aG docker jenkins
sudo systemctl restart jenkins


Step 10: Create Jenkinsfile

Frontend Example:

pipeline {
    agent any

    stages {

        stage('Checkout') {
            steps {
                git branch: 'main',
                url: 'https://github.com/<repo>.git'
            }
        }

        stage('Build Image') {
            steps {
                sh 'docker build -t petstore-frontend .'
            }
        }

        stage('Push ECR') {
            steps {
                sh '''
                aws ecr get-login-password --region ap-south-1 | \
                docker login --username AWS \
                --password-stdin <ACCOUNT>.dkr.ecr.ap-south-1.amazonaws.com

                docker tag petstore-frontend \
                <ACCOUNT>.dkr.ecr.ap-south-1.amazonaws.com/petstore-frontend:latest

                docker push \
                <ACCOUNT>.dkr.ecr.ap-south-1.amazonaws.com/petstore-frontend:latest
                '''
            }
        }
    }
}



Step 11: Configure Jenkins to Deploy

Jenkins must SSH into Frontend and Backend EC2s.

Generate Key:
ssh-keygen

Copy:
ssh-copy-id ec2-user@FRONTEND-IP

ssh-copy-id ec2-user@BACKEND-IP

Step 12: Deployment Script

Frontend EC2:
docker pull <ECR-URL>:latest

docker stop frontend || true
docker rm frontend || true

docker run -d \
--name frontend \
-p 80:80 \
<ECR-URL>:latest

Backend EC2:
docker pull <ECR-URL>:latest

docker stop backend || true
docker rm backend || true

docker run -d \
--name backend \
-p 8080:8080 \
<ECR-URL>:latest
