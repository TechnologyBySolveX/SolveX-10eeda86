CREATE TABLE problems (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(255) NOT NULL,
    slug VARCHAR(255) UNIQUE NOT NULL,
    description TEXT NOT NULL,
    difficulty ENUM('EASY','MEDIUM','HARD') NOT NULL,
    constraints TEXT,
    example_input TEXT,
    example_output TEXT,

);

tags Table (Problem Categories)
CREATE TABLE tags (

problem_tags (Many-to-Many)
CREATE TABLE problem_tags (
    problem_id BIGINT,
    tag_id BIGINT,
    PRIMARY KEY (problem_id, tag_id),
    FOREIGN KEY (problem_id) REFERENCES problems(id),
    FOREIGN KEY (tag_id) REFERENCES tags(id)
);

submissions Table
CREATE TABLE submissions (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    problem_id BIGINT NOT NULL,
    code TEXT NOT NULL,
    language VARCHAR(50),
    status ENUM('ACCEPTED','WRONG_ANSWER','TLE','RUNTIME_ERROR') NOT NULL,
    execution_time INT,
    memory_used INT,
    submitted_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    FOREIGN KEY (user_id) REFERENCES users(id),
    FOREIGN KEY (problem_id) REFERENCES problems(id)
);

How to Deploy the WAR File on EC2 instance Step by Step processs :



INAL, WORKING SOLUTION
Spring Boot (WAR) + External Tomcat on EC2

This is how JSP apps are deployed in real production.

🟢 STEP 1: Prepare Your Spring Boot Project (LOCALLY)
1️⃣ Change packaging to WAR

pom.xml

<packaging>war</packaging>

2️⃣ Add JSP dependencies
<dependency>
    <groupId>org.apache.tomcat.embed</groupId>
    <artifactId>tomcat-embed-jasper</artifactId>
</dependency>

<dependency>
    <groupId>jakarta.servlet.jsp.jstl</groupId>
    <artifactId>jakarta.servlet.jsp.jstl-api</artifactId>
</dependency>

<dependency>
    <groupId>org.glassfish.web</groupId>
    <artifactId>jakarta.servlet.jsp.jstl</artifactId>
</dependency>

3️⃣ Extend SpringBootServletInitializer
@SpringBootApplication
public class UserAuthentocationApplication
        extends SpringBootServletInitializer {

    @Override
    protected SpringApplicationBuilder configure(SpringApplicationBuilder builder) {
        return builder.sources(UserAuthentocationApplication.class);
    }

    public static void main(String[] args) {
        SpringApplication.run(UserAuthentocationApplication.class, args);
    }
}

4️⃣ Correct JSP location (VERY IMPORTANT)
src/main/webapp/WEB-INF/jsp/
    └── login.jsp


❌ Do NOT put JSP in resources/templates

5️⃣ application.properties
spring.mvc.view.prefix=/WEB-INF/jsp/
spring.mvc.view.suffix=.jsp

6️⃣ Build WAR
mvn clean package


Output:

target/UserAuthentocation.war

🟢 STEP 2: Setup EC2 (Amazon Linux / Ubuntu)
1️⃣ SSH into EC2
ssh -i your-key.pem ec2-user@EC2_PUBLIC_IP

2️⃣ Install Java (17 recommended)
sudo yum install java-17-amazon-corretto -y
java -version

3️⃣ Install Tomcat
sudo yum install tomcat -y


Start Tomcat:

sudo systemctl start tomcat
sudo systemctl enable tomcat


Check:

sudo systemctl status tomcat

4️⃣ Open Port 8080 (EC2 Security Group)

Inbound Rule:

Type	Port	Source
Custom TCP	8080	0.0.0.0/0
🟢 STEP 3: Deploy WAR to Tomcat
1️⃣ Copy WAR to EC2

From local machine:

scp -i your-key.pem target/UserAuthentocation.war ec2-user@EC2_PUBLIC_IP:/home/ec2-user/

2️⃣ Move WAR to Tomcat webapps
sudo mv UserAuthentocation.war /usr/share/tomcat/webapps/


Restart Tomcat:

sudo systemctl restart tomcat

🟢 STEP 4: Access Your JSP Application

Open browser:

http://EC2_PUBLIC_IP:8080/UserAuthentocation/


OR if controller mapping:

@GetMapping("/")


Then:

http://EC2_PUBLIC_IP:8080/UserAuthentocation/

🟢 STEP 5: Verify JSP Compilation (DEBUG)

Check logs:

sudo tail -f /var/log/tomcat/catalina.out


You should see:

Deploying web application archive UserAuthentocation.war


If JSP fails, errors appear here.

🔥 COMMON EC2 MISTAKES (CHECK)
Issue	Fix
JAR used	Must use WAR
JSP inside resources	Must be webapp/WEB-INF
DevTools enabled	Remove in prod
Port not open	Open 8080 SG
Using root DB	Use app user
🚀 OPTIONAL (BEST PRACTICE)

Use Nginx in front of Tomcat

Enable HTTPS

Run Tomcat behind domain

Use systemd service

✅ FINAL ANSWER

JSP WILL NOT WORK RELIABLY WITH JAR ON EC2

✔ WAR + External Tomcat = 100% working

✔ This is how real production apps run
