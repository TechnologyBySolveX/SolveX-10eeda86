Deploying the Spring Boot As WAR File 

Install Docker on AWS Ubuntu
On your EC2 instance:
sudo apt-get update
sudo apt-get install docker.io -y
sudo systemctl start docker
sudo systemctl enable docker

After that we can Build & Run Container 
# Copy WAR + Dockerfile to server
scp -i your-key.pem target/your-app.war ubuntu@<EC2-IP>:/home/ubuntu/

# Build image
docker build -t springboot-war-app .

# Run container
docker run -d -p 8080:8080 springboot-war-app


Configure AWS Security Group
Go to your EC2 instance’s Security Group in AWS console.

Add an Inbound Rule for TCP 8080 (or whichever port you exposed).

Now you can access:
http://<EC2-Public-IP>:8080



Steps for WAR Deployment in Docker

Build the WAR File
If you’re using Maven:

mvn clean package

WAR will be in target/your-app.war

Dockerfile for WAR Deployment
Instead of running with java -jar, you’ll use a Tomcat base image:

# Use official Tomcat image with JDK
FROM tomcat:9.0-jdk17

# Remove default ROOT application
RUN rm -rf /usr/local/tomcat/webapps/ROOT

# Copy your WAR file into Tomcat's webapps directory
COPY target/your-app.war /usr/local/tomcat/webapps/ROOT.war

# Expose Tomcat port
EXPOSE 8080

# Start Tomcat
CMD ["catalina.sh", "run"]
